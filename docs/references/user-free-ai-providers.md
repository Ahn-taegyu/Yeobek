# 사용자 요청

> 좋아. Gemini 무료 API로 생성하고 Groq로 평가할 수 있도록 어댑터를 추가해줘. 내가 발급해야 할 키와 설정 방법도 정리하고 유료 호출은 하지 마.

앞선 맥락에서 Liner 크레딧이 아직 제공되지 않았고 OpenAI 크레딧이 없는 상황의 무료 시험 방법을 물었다.

# 반영 범위

[키 당일 점검표](../specs/key-day-checklist.md#무료-텍스트-제공사-선택-시험)는 선택적 텍스트 시험의 계정 확인과 키 설정을 설명한다. [AI 하네스](../specs/ai-harness.md)는 구현 경계를 설명한다. 유료 호출 없이 실제 외부 호출은 수행하지 않았다.
