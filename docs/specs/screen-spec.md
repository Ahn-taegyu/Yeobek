# 화면 명세 사용법

[기능명세](functional-spec.md)의 화면 부속 문서다. [D-017](../decisions/D-017-p0-feature-spec.md)의 최신 P0 요구와 기존 화면 ID를 함께 사용한다. SC는 논리 화면 또는 영역을 가리킨다.

# 공통 구성

- **작가 작업 공간:** 전시명·초안/공개 상태·작가 홈·로그아웃, `작품/자료`, `검수`, `게시/배포` 이동, 저장 상태를 제공한다. 상세 작업에는 선택 작품 번호·제목을 고정 표시한다.
- **관람 화면:** 전시명, 현재 작품, 대화, 입력/출력 모드, 입력부가 기본이다. 별도 로그인·설정 가입 흐름은 없다.
- **상태:** 불러오는 중, 데이터 없음, 입력 오류, 처리 중, 성공, 처리 실패, 권한/공개 차단을 구별한다. 재시도 버튼은 같은 작업에 연결한다.
- **변경 보호:** 미저장 이탈은 계속 편집/저장 후 이동/버리기. 삭제·중지·철회는 대상과 영향 범위를 확인한다. 일반 저장·패널 닫기에는 불필요한 확인을 넣지 않는다.
- **접근성:** 보이는 라벨·키보드 포커스·색상 외 상태 표식·이미지 대체문을 제공한다. 동작 버튼은 터치하기 쉬운 크기로 설계하고 모바일 키보드 위에 입력부를 유지한다.

# SC-A01 작가 로그인

**목적/전제:** 기존 또는 직접 가입한 작가 계정으로 자기 전시에 접근한다. 관람객 로그인 화면으로 사용하지 않는다. OP-01, BR-01·16, UC-21~22.

| 화면 영역 | 표시·입력 | 동작/조건 |
| --- | --- | --- |
| 안내 | 서비스명, 작가 관리 화면 안내 | 관람객 기능과 구분 |
| 폼 | 이메일, 비밀번호, 표시/숨김 | 이메일 형식·필수값만 선검증, 비밀번호 정책을 로그인에서 새로 제한하지 않음 |
| 주 행동 | `로그인` | 필수값 유효 시 가능, 진행 중 중복 제출 방지 |
| 오류 | 필드/인증/네트워크 안내 | 어느 계정이 존재하는지 구별해 노출하지 않음 |

- 성공: 작가 홈 SC-A02로 이동한다. 외부 URL을 임의 복귀 경로로 사용하지 않는다.
- 실패: 이메일은 유지, 비밀번호는 브라우저 메모리 외 저장하지 않는다. 재시도 가능 여부를 표시한다.
- 세션 만료: 같은 탭 재인증 동안 가능한 미저장 입력은 메모리에서 유지하되 자동 저장·자동 재승인하지 않는다. 다른 계정으로 로그인하면 이전 작가 초안을 지운다.
- 회원가입 이동을 제공한다. 비밀번호 찾기 범위는 미정이다.

# SC-A02 작가 홈

**목적/전제:** 자기 작가 정보와 전시 기록을 보고 새 전시를 시작한다. OP-02, OP-21~22, BR-01·15. 기존 전시 목록 화면의 ID를 유지한다.

| 영역 | 내용 | 동작 |
| --- | --- | --- |
| 작가 정보 | 기본 작품 세계 등록 전/완료 | SC-A10 입력·수정으로 이동. 미등록 상태에서도 새 전시 시작 가능 |
| 전시 기록 | 자기 전시 제목·기간·장소, 준비/공개/중지 상태, 작품 수 | 선택→기존 SC-A03; 처음엔 최근 수정순 제안 |
| 주 행동 | `새 전시 시작` | 빈 SC-A03 입력 화면. 버튼만으로 DB에 빈 전시를 만들지 않음 |
| 빈 상태 | 작가 정보 미입력, 전시 없음의 안내를 구분 | 작가 정보 입력 또는 새 전시 시작 |
| 계정 | 로그인 계정 표시, 로그아웃 | 로그인 이메일을 공개 작가명으로 사용하지 않음 |

작가 소개는 전시별로 다시 입력하지 않는 공통 원본이다. 저장한 내용은 [AI용 내부 지식](artist-knowledge.md)으로 연결되지만 화면에 위키 구조·문서 ID·Markdown 편집기를 노출하지 않는다. 작가 정보 저장은 공개 전시 갱신과 별개이며 적용이 필요한 전시에서 검수·게시한다.

전시 기록은 서비스에 등록한 전시만 표시하고 지난 전시를 자동 삭제하지 않는다. 관람 통계·외부 전시 수집·전시 복제 기능으로 확대하지 않는다. 목록 실패와 빈 기록을 구분하며 계정 설정 확장은 기존 범위 밖이다.

# SC-A03 전시 정보 입력·작업 공간

**목적/전제:** 새 전시의 정보를 입력하거나 기존 전시 준비를 이어간다. 기존 전시는 소유권 확인 후 연다. OP-02~04, OP-08, OP-12, OP-22.

| 영역 | 내용 | 행동/조건 |
| --- | --- | --- |
| 전시 헤더 | 제목·공개 상태, 현재 공개 수, 변경 미게시 표시 | `게시/배포`→A06 |
| 기본 정보 | 제목·소개/주제·기간·장소, 연결 작가의 이름·소개 요약 | 새 전시 `저장하고 작품 추가`, 기존 `저장`; 작가 정보 수정은 A02 |
| 준비 요약 | 자료 부족/검수 필요/음성 필요/게시 가능 개수 | 해당 작품/상태로 이동 |
| 작품 목록 | 번호·썸네일·제목, 초안 준비 상태와 공개 상태를 별도 표시 | `편집`→A04, `검수`→A05 |
| 목록 도구 | 번호/제목 검색, 준비 상태 필터, `작품 추가` | 새 작품 폼 A04 |

1단계 전시 기본 정보와 2단계 전시별 작품 세계를 같은 전시 초안으로 관리한다. 임시저장 API는 필수값 누락을 허용한다. 이전 이동은 값을 보존하고 다음 버튼은 저장과 단계 진행을 연결한다. 다음 및 최종 완료 시 필수 기본 정보와 기간을 검사하며 2단계 모든 질문은 선택이다. 완료 후 SC-A04로 이동한다. 기존 전시 관리는 같은 SC-A03의 작업 영역으로 연결한다.

# SC-A04 작품·자료 편집

**목적/전제:** 작품을 식별하고 생성·검수에 필요한 자료를 연결한다. OP-04~07, OP-13, BR-01~03·06~07.

| 영역 | 필드/정보 | 행동 |
| --- | --- | --- |
| 작품 정보 | 번호, 제목, 제작연도·재료·크기 | 필수/선택·길이·번호 충돌 인라인 표시 |
| 대표 이미지 | 미리보기, 파일명·크기, 업로드 상태 | 추가/교체/초안 연결 제거; 완료 전 공개 이미지로 사용 금지 |
| 비공개 메모 | 자유 입력, “이 메모는 그대로 공개되지 않아요” | 필요한 부분을 근거 초안에 등록 |
| 도록 보관 | PDF 목록·파일명·업로드 상태 | 업로드, 소유자 원본 열기, 삭제; “PDF 내용은 직접 발췌해 주세요” |
| 근거 편집 | 본문, 출처 라벨, 파일·쪽수, 작품/전시 공통/연결 작가 공통의 구분 | 추가/수정/초안 제외; 공개 승인 여부는 별도 표시 |
| 저장 영역 | 저장 상태/시각, 공개본 유지 안내 | `저장`, `저장 후 검수`, 목록 복귀 |
| 위험 행동 | 작품 삭제, 자료 삭제/공개 근거 철회 | 영향 조회 후 별도 확인, 단순 초안 제외와 구별 |

**활성 조건:** F02에 따라 제목 등 필드가 비어 있거나 첨부 자료가 없어도 일부 입력을 초안으로 저장할 수 있다. 입력된 번호의 형식과 전시 내 중복은 검증한다. `저장 후 검수`는 저장 성공 후 이동하되 근거가 부족하면 A05에서 부족 항목을 안내한다. 필드/파일 상한은 기능명세 4.1을 그대로 사용한다.

**세부 동작:** 전시 공통 PDF·근거와 연결 작가의 공통 정보는 기존 자료에서 선택한다. 작가 공통 정보의 정정은 A02, 전시 공통 정보의 정정은 A03으로 연결한다. 다른 전시 작품의 내용을 자동 선택하지 않는다. 공개 근거 수정은 새 초안으로 저장한다. 활성 공개 자료를 제거하려면 “초안에서 제외”와 “공개 철회”의 결과를 명확히 구분한다. 공개 파일의 교체/삭제는 참조 검사 없이 덮어쓰지 않는다.

**예외 상태:** 중복 번호→번호 필드 유지·수정; 파일 오류→문제 파일만 재선택; 업로드 중→텍스트 편집 가능·해당 파일 사용 불가; 충돌→로컬 입력 보존·최신본 조회; 공개 중 번호 변경→게시 시 적용/라벨 재출력 안내. 외부 전시·다른 작가 자료 선택은 허용하지 않는다.

# SC-A05 기본 해설 원고 검수와 별도 AI 미리보기

**목적/전제:** 근거와 해설을 대조해 승인하고 음성을 준비한다. OP-08~11, OP-20, BR-03~04.

| 영역 | 표시 정보 | 행동/활성 조건 |
| --- | --- | --- |
| 선택 작품 | 번호·제목·이미지, 초안/공개 상태 | 다른 작품 선택 전 미저장 보호 |
| AI 참고 정보·근거 패널 | 작가 공통/전시 공통/이 작품의 구분, 선택 근거·출처·쪽수·사용 버전·공개 승인 상태 | 원본 확인(작가 전용), `근거 공개 승인`, A02/A03/A04의 원래 입력 수정 연결 |
| 기본 작품 소개 | 기본 생성 원고, 인용 근거, 글자 수, 검토 경고 | 직접 수정·저장, 새 후보 적용 또는 기존 원고 유지 |
| 검수 확인 | 근거 준비 여부, 미승인 인용/변경 충돌 | `해설 승인`: 저장 완료+사용 근거 공개 승인 조건 |
| 기본 음성 | 미준비/생성 중/준비/실패/오래된 음성, 같은 승인 글 | `음성 만들기`, `재시도`, `재생/일시정지` |
| 다음 행동 | 미해결 조건 목록 | `게시/배포로 이동`→A06; 이동과 게시 실행은 별개 |

넓은 화면은 근거와 해설을 나란히 놓고, 좁은 화면은 순서가 분명한 접이식 영역으로 만든다. 원본 PDF·승인 전 음성 미리보기는 인증된 관리자 경로로만 열며 공개 API를 우회하지 않는다.

**상태별 제어:** 근거 없음→생성 비활성+자료 입력 CTA; 생성 중→중복 생성 비활성; 후보 도착→자동 덮어쓰기 없음; 인용 오류→승인 비활성; 승인 후 수정→재승인 필요/음성 stale; 음성 실패→승인 글 보존·음성만 재시도; 이전 공개본 존재→관람에 제공되는 버전 별도 표시.

실시간 관람객 답변을 이 화면에 모아 일일이 승인하는 기능은 만들지 않는다. 전체 버전 이력 비교 도구 대신 현재 공개본·편집본·이번 생성 후보를 구별한다. 이 근거 패널 보완은 작가 열람 질문에 대한 제안이며 별도 위키 탐색 화면을 추가하는 요구가 아니다.

SC-A05는 기본 해설 원고 검수와 작가 전용 AI 미리보기의 두 하위 경로로 나눈다. 기본 생성 작품 소개는 원고 화면에서 직접 편집할 수 있다. 나머지 생성 답변은 지시문으로 새 후보를 만든다. AI 미리보기에는 답변별 정확성 평가·수정 요청과 원고 검수 복귀를 제공한다. 수정 후보는 다시 검수·승인하고 게시에서 공개 버전을 변경한다. [v3 검수 결정](../references/user-v3-review-decisions.md).

# SC-A06 게시·중지·배포

**목적/전제:** 무엇이 공개되는지 검토하고 공개 전시 주소를 배포한다. OP-12~14, BR-05~08.

| 영역 | 정보 | 행동/조건 |
| --- | --- | --- |
| 전시 공개 요약 | 현재 공개/중지 상태, 공개 작가명·기본 정보의 변경 여부 | `전시 정보만 게시`: 기존 공개 작품이 있을 때 |
| 공개 조건 | 전시 기본 정보·등록 작품·검수 상태·현재 공개 버전 | 미완료 이유와 보완 화면 링크. 이미지는 선택. 시험용 해설은 운영 게시 차단 |
| 게시 행동 | 게시할 작품 수·유지할 기존 작품 수 | 최초 `공개 시작`, 이후 `선택 변경 게시`; 선택 전체 검증 |
| 공개 관리 | 현재 공개 작품 목록 | `작품 공개 중지`, `전시 전체 중지`, 조건 충족 시 `다시 공개` |
| 배포 | 전시 링크, 번호 라벨 | 링크 복사와 기존 라벨 제공. QR 제작은 MVP에서 보류 |

**게시 확인:** 선택 작품·변경 정보·유지할 작품·누락된 준비 항목을 보여준다. 서버에서 조건이 바뀌면 확인 창에 최신 사유를 표시하고 일부만 성공한 것처럼 진행하지 않는다. 중지 확인은 전시 전체/작품 하나의 영향을 분명히 표시한다.

**상태:** 최초 미공개는 배포 버튼 대신 게시 준비 안내; 공개 성공은 성공 시각·공개 작품과 링크 표시; 수정 초안은 공개 링크와 미게시 변경을 함께 표시; 중지 상태는 링크 자체는 유지하되 “현재 관람 불가” 표시와 새 인쇄 비활성. 게시 실패 시 기존 링크·공개 버전을 유지한다.

번호 변경 후 게시 성공 시 라벨 재출력 안내를 남긴다. 공개 주소와 기존 서버 계약을 유지한다.

# SC-A07 인쇄용 번호 라벨

**목적/전제:** 실제 현장에 부착할 출력물을 만든다. 현재 공개 전시·작품만 대상이다. OP-14~15, BR-06·09.

| 영역 | 내용 | 행동 |
| --- | --- | --- |
| 인쇄 설정 | 공개 작품 번호 라벨 | 라벨 다운로드 |
| 전시 안내 | 전시명·작가명, 짧은 시작 안내·공개 주소 | 공개 주소로 진입 |
| 작품 라벨 | 공개 번호·제목 | 번호 갱신이 공개본에 반영되면 라벨 재다운로드 |
| 도구 | A4 미리보기, 브라우저 인쇄/저장 안내 | `인쇄 / PDF로 저장`은 브라우저 인쇄 대화상자 |

인쇄 직전 공개 상태·번호를 다시 확인한다. 변경되면 최신 라벨을 재구성한 뒤 다시 인쇄하도록 한다. 출력에는 관리자 메뉴·버튼·비공개 정보가 없어야 한다. 브라우저 인쇄 취소는 게시 상태를 바꾸지 않는다. 앱 내 PDF 엔진·단축 URL 서비스·NFC 제작은 필요하지 않다.

# SC-V01 통합 도슨트 채팅

전시 소개에서 넘어오면 상단에 여백 로고와 음소거 버튼, 초기 영역에 전시명과 안내 문구, 입력 영역에 글 입력·전송·녹음·작품 선택을 표시한다. 첫 질문 전송 후 안내를 접고 같은 채팅에 질문·답변을 쌓는다. 처리 상태와 재시도를 안내한다.

녹음 버튼을 눌러 시작하고 다시 눌러 종료한다. 권한은 첫 녹음 동작에서 요청한다. 인식 결과 확인 후 전송 또는 즉시 전송은 미정이다. 현재 구현과 검사에서는 기존 확인 후 전송을 기준으로 둔다. TTS 실패·음소거 상태에서도 글 답변을 읽을 수 있다. 음소거는 진행 중인 낭독을 멈추며 해제 후 새 답변에 적용한다. 브라우저가 자동재생을 제한하면 재생 행동을 제공한다.

선택 작품명이 상단 로고를 대체하고 목록을 여는 역할을 한다. 재선택은 현재 작품을 해제하고 전시 전체 맥락과 로고로 돌아간다. 선택·다른 작품으로 변경·해제 시 채팅을 유지한다. 작품 선택은 질문을 보내거나 해설을 재생하지 않는다.

# SC-V02 공개 작품 한 줄 목록과 전체보기

작품 선택 버튼이나 상단 작품명으로 공개 작품의 가로 한 줄 목록을 연다. 번호·작품명·이미지와 선택 상태를 표시하며 이미지가 없으면 대체 표시한다. 한 줄 목록에서는 채팅 입력에 계속 접근할 수 있다. 전체보기는 커진 목록이 채팅을 가리며 목록을 닫거나 작품을 고르면 원래 채팅으로 돌아간다. 고르지 않고 닫으면 기존 선택을 유지한다. 공개 작품 번호와 순서는 게시된 버전을 따른다.

# SC-V03 답변 근거 패널

**목적:** 해당 답변의 공개 근거를 확인한다. OP-15/17, BR-08·10.

표시 순서는 대상 작품, `승인 해설` 또는 `AI 답변` 구분, 출처 라벨·쪽수·허용 발췌다. 답변 전체를 작가가 승인했다고 오인시키지 않는다. 내부 evidence ID, 원본 파일 경로, 원본 다운로드 버튼은 노출하지 않는다.

현재 공개 상태를 재검사하고 철회/교체된 근거는 표시하지 않는다. 출처가 없는 확인 질문/근거 부족 메시지에는 빈 출처 패널 버튼을 만들지 않는다. 닫으면 원래 메시지 위치로 복귀한다.

# SC-V04 공개 이용 불가

**목적:** 잘못된 URL·미공개·중지·삭제에 일관되게 대응한다. OP-15, BR-07~08.

| 상황 | 화면과 복구 |
| --- | --- |
| 전시 전체 접근 불가 | “현재 이용할 수 없는 전시예요. 전시장 안내를 확인해 주세요.”, 공개 상태 다시 확인 |
| 작품만 이용 불가, 전시 공개 | 해당 작품 내용을 숨기고 “이 작품은 현재 안내할 수 없어요”, 공개 작품 목록으로 이동 |
| 일시 통신 실패 | 이용 불가 확정과 구별해 “연결을 확인해 주세요”, 재시도 |
| 공개 작품 0개 | 전시 paused 상태의 이용 불가 안내; 빈 채팅에서 계속 질문하게 두지 않음 |

사전에 공개되지 않은 전시명·작품명·소유자를 오류 화면에 노출하지 않는다. 미존재/비공개/삭제를 구분해 내부 상태를 추측하게 하지 않는다. 전체 중지 시 질문·녹음·음성 재생을 차단한다. 작품 중지 후 다른 공개 작품 탐색은 가능하다.

# SC-V05 전시 소개

공개 전시 주소로 진입한다. 공개 확인 후 전시명·장소·기간과 '여백 채우러 가기'를 제공한다. 버튼을 누르면 V01을 연다. 특정 작품을 자동 선택하지 않는다. 비공개·중지·잘못된 링크는 V04에서 처리한다.

# SC-V06 작품 정보

**목적:** 작품 이미지와 기본 정보를 보고 같은 채팅의 질문 대상으로 선택한다. OP-15, BR-08~09·12. 관람객용 내부 위키 화면이 아니다.

| 영역 | 내용/동작 |
| --- | --- |
| 작품 정보 | 공개 이미지·번호·제목·작가명, 공개된 제작연도·재료·크기. 없는 항목은 생략 |
| 질문 대상 | `이 작품으로 질문`→대상 설정 후 V01로 복귀; 자동 전송 없음 |
| 해설 | `해설 보기`→이 작품을 대상으로 같은 V01에 명시적 해설 요청 |
| 닫기/뒤로 | 원래 목록/채팅 위치로 복귀. 탐색만으로 선택·입력·모드를 바꾸지 않음 |
| 변경/중지 | 현재 공개본 재확인. 중지된 이미지·정보 숨기고 V04 또는 목록 복귀 |

모바일은 상세 시트/화면, 넓은 화면은 정보 패널로 구현할 수 있다. 상세 안에 두 번째 채팅이나 별도의 Q&A 기록을 만들지 않는다. 이미지 표시와 AI 이미지 분석·부위 선택은 다른 기능이며 후자는 기존 후순위다.

# 작가 인증 화면 연결

[D-016](../decisions/D-016-artist-auth.md)과 Notion F13에 따라 AUTH-00은 SC-A08, AUTH-01은 기존 SC-A01, AUTH-02는 SC-A09, AUTH-03은 로그아웃에 대응한다. 논리 화면의 물리적 분리와 배치는 설계 제안이다.

## SC-A08 로그인·회원가입 선택

비로그인 작가에게 서비스 식별과 로그인·회원가입 선택을 표시한다. 각 버튼은 SC-A01과 SC-A09로 연결하며, 선택만으로 계정을 생성하지 않는다. 유효한 로그인 세션은 확인 후 자기 홈 SC-A02로 연결한다. 세션 확인 중 로딩, 실패 시 재시도를 제공한다. OP-01, BR-16, UC-20.

## SC-A09 작가 회원가입

이메일, 비밀번호, 비밀번호 확인, 가입 버튼, 로그인 이동, 뒤로 가기 및 오류 안내를 제공한다. 제출 시 필수값·이메일 형식·비밀번호 8자 이상과 확인값 일치를 검증하고 처리 중 중복 제출을 방지한다. 가입 요청이 접수되면 필수 이메일 인증을 안내한다. 이메일 인증을 마치면 SC-A01에서 직접 로그인한다. 가입에 작가 소개·작품 세계 입력을 요구하지 않는다. OP-23, BR-16, UC-22~23. [가입 인증 결정](../references/user-signup-security.md).

필드 오류는 해당 입력과 연결하고, 중복 가입·통신 실패·응답 유실은 안내와 수동 복구 경로를 제공한다. 이메일 인증 대기·완료·실패 상태를 구분한다. 재발송 절차는 미정이다. 화면 전환 시 비밀번호를 제거한다. 가입 또는 이메일 인증만으로 관리자 세션을 열 수 없도록 제공사 연동을 설계한다.

## SC-A01과 로그아웃 연결

로그인에서 가입 화면과 선택 화면으로 이동할 수 있다. 서버 인증에 성공하면 자기 홈으로 이동한다. 기존 인증 실패·만료 처리와 소유권 검사를 유지한다. 로그아웃이 성공하면 서버 세션을 종료하고 선택 화면을 표시한다. 종료 실패는 재시도할 수 있게 안내한다.

작가 가입 선택·가입 화면과 직접 로그인 연결은 구현 전이다. 기존 로그인 화면의 현재 상태는 [개발 기반](development-foundation.md)에서 확인한다.

# v3 변경분 연결

v3 화면 대조는 작가 Figma 176:331·관람객 165:616을 해당 묶음 재개 시 직접 확인한다. 로그인 후 온보딩의 이름·작가명·이메일은 필수다. 나머지는 건너뛸 수 있고 성별은 기본 수집하지 않는다. 홈은 준비중(미공개 또는 시작 전), 진행중(공개·기간 내), 종료(종료 시각 경과)를 표시한다. 상태가 겹칠 때의 탭 우선순위는 미결정이다. 별도 도슨트 여운 화면과 QR 제작은 MVP에서 제외하고 관람 서버 계약은 유지한다. 세부 화면 구성은 프런트에서 결정한다.
