# 우선순위 해석

사용자가 **볼드 = 1순위**, *이탤릭 = 2순위*라고 지정했다. 강조 없는 항목은 `unspecified`로 보존한다. Notion의 '3순위'로 대체하지 않는다. 아래는 오탈자·장난 기호만 정리한 목록이며, 별도 범위 변경 응답 전까지 원안이다.

# 사용자 목록

1. 정보 입력
   - *AI 인터뷰*
   - **작가 제공 자료 받기(도록 포함)**
   - **이미지 포함**
   - **작가 검수**
2. 도슨트
   - **해설 생성 — 음성·글 모두**
   - **AI 질의응답**
   - 개인 맞춤형 동선 — 시간·관심사에 따라
   - *그룹 관람*
   - **작품 인식 — 숫자 라벨, QR, NFC 태그, 위치 인식**
   - 음성 설정 — 다양한 프리셋, 작가 목소리
   - **작품 리스트**
   - 전시 지도
3. 관람 중
   - 작품별 감상평·댓글
4. 관람 후
   - 개인 기록
   - 후기
5. *데이터 수집*
   - *어디서 오래 머물렀는지*
   - *후기*
   - *댓글이 많이 달린 작품*
   - *많이 받은 질문*
   - *감정적 영향을 받은 지점*

# 요청 범위

개발을 시작하도록 docs를 만들고 OKF·RAG·Obsidian Bases로 기획을 정리한다. 먼저 MVP 우선순위를 점검하고 기능명세서를 만든다. 기존 문서의 미확정 사항, 과도한 설계, 불필요한 내용과 누락을 검토한다. 불확실한 정보는 사용자에게 묻는다.
