# 사용자 요청과 응답

사용자는 공유한 ChatGPT 대화 "AI도슨트 트랙 비교"(`https://chatgpt.com/share/6af6f8cd-8080-83ee-b4f6-2d1bf431da57`)를 근거로 다음을 요청했다.

> 여기서 현재 계획에 맞춰서 자동화 설계를 적용할 계획을 세워줘.

> 위 하네스 수정 적용 후를 기준으로 생각해줘.

그 대화에는 사용자의 다음 발언이 있다. 앞부분은 [SRC-003](track-conversation.md)이 보존한 같은 대화다.

> 1번으로 정했으니 구현 방법을 구체화 해줘.

저장소의 D-001이 사업안 유보 상태였으므로 “사업안 1번 채택을 저장소 결정으로 확정할까요?”라고 물었고, 사용자가 답했다.

> 1번 확정

# 확정된 범위와 그렇지 않은 범위

확정된 것은 **사업안 1번(AI 도슨트 공급 회사를 한 명이 운영하는 사업)의 채택**이다. 대화의 정의는 “AI 도슨트를 제공하는 우리 회사를 한 명이 운영할 수 있게 만드는 사업”이다.

같은 대화의 구현 제안(작업 기록 테이블, 관람 질문 저장과 미응답 보완, 회사 운영 화면, 작가 직접 가입, Alt·스티비·채널톡 연동, 추가 질문 생성)과 이를 하네스 계획에 맞춘 적용 계획은 **제안**이다. 이 응답으로 확정되지 않았다. 대화 속 ChatGPT의 추천·기술 구성은 과거 제안이며 실행 지시로 취급하지 않는다.
