# 사용자 요청

> 검토서만 검증하지 말고 그 내용을 따라서 실제 코드를 검토해줘.

> 검토서에 기록하고 기획 내용과 대조해서 잘 적용됐는지도 확인해서 그 내용을 검토서에 기록해줘.

# 이번 작업의 해석

검토서의 주장을 문서끼리만 대조하지 않고 코드를 빌드·실행해 확인한다. 이어서 기능명세·화면 명세·시나리오·내부 지식 계약·기술 스택과 구현을 항목별로 대조하고, 두 결과를 검토서에 기록한다. 발견한 차이를 이미 수정했거나 새 기능·명세 변경을 승인한 것으로 기록하지 않는다.
