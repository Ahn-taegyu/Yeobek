# 질문과 답변

음성 입력·번호 동작에 대한 답변:

> 음성 인식문 확인 후 전송하고 번호나 작품을 지칭하는 이야기를 물어봤을 때 자동으로 AI가 필요한 답변을 찾아서 하면서 상단에 작품도 선택되어야 해.

공개 번호 변경 시점 답변: **다음 게시 시점에 적용 (추천)**

기본 해설의 미리 생성한 저장 음성과 예상 Q&A 게시 조건을 설명한 뒤 받은 답변:

> 음성은 TTS자동 생성으로 하는게 나을 것 같고 예상 Q&A는 그냥 작가가 어떻게 답변이 나오는지 확인하고 수정할 게 있으면 요청하는 용도야.

후속 확인 질문: 자동 TTS는 관람객이 음성을 켜고 답변을 받을 때 생성하고, 음성 준비 여부와 관계없이 승인된 글로 전시를 공개하는 방식으로 할까요? 작가용 예상 Q&A의 승인본은 앞서 정한 대로 관람 답변의 근거로만 사용하며, 원문 그대로 재생하지 않습니다.

# 적용 경계

예상 Q&A 개수·평가 횟수를 게시 필수 조건으로 요구하지 않는다. 기본 해설/사용 근거 승인과 명시적 게시 단계는 유지하며 승인 QA는 생성 근거로 사용한다. 저장 음성 사전 준비는 게시 필수에서 제외하고 관람 출력 음성은 답변 시 TTS로 생성한다. 질문의 작품이 명확하면 해당 선택을 상단에 반영하되 잘못된 번호·모호한 지칭의 처리까지 모델 추측으로 확정하지 않는다. 이 경로의 구현과 기존 계약·플래그·CI·환경 예제 변경은 B 담당이며 이 출처만으로 구현 완료가 아니다.
