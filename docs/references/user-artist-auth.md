# 전달받은 결정

> - 로그인 완료 후 작가 홈에서 자신의 전시 목록을 확인하고 새로운 전시를 생성할 수 있다.

# 문서 반영 요청과 경계

사용자는 사전 생성 계정 전용·공개 회원가입 제외 정책의 충돌 해소, 세 논리 화면(선택·로그인·회원가입), 버튼/검증/상태/시나리오/수용 기준/계정 데이터의 상세화를 요청했다. 실제 페이지 분리는 설계 제안으로 관리한다. 이메일 인증·소셜 로그인·비밀번호 정책은 확정하지 않고 proposed 또는 미결정으로 남긴다.
