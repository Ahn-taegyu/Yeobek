## AI 인터뷰 설계

- **흐름:** 작품별로 "인터뷰 시작" → AI가 작품 사진과 글 자료를 보고, 자료에 답이 없는 질문을 만듦 → 작가가 글로 답하거나 건너뜀 → 답변이 근거로 저장됨 → 해설·예상 질문·관람 답변에 사용.
- **만들 것:** 질문·답변 저장 테이블과 권한, 사진을 읽는 생성 절차(기존 작업 원장·한도 재사용), API 3개(생성·목록·답변 저장), 화면, 기본 꺼짐 플래그.
- **제가 둔 가정** (다르면 알려 주세요):&#x20;
  - 작품당 질문은 최대 5개.
  - 답변은 글 입력만 받음.
  - 답변은 저장 시 근거 초안이 되고, 인터뷰 화면에서 "공개 근거로 사용"을 눌러야 승인됨.
  - 해설 생성 때 나오는 보완 질문(최대 3개, 지금 화면에 안 보임)은 그대로 두고 인터뷰와 합치지 않음.
- **이름:** 기존 F03(녹음 인터뷰, P1)과 다른 기능이므로 새 기능 ID를 붙입니다.
