# 사용자 요청

> 전시 등록 할 때 "자주하는 질문", "학습된 여운 체험하기", "기본 해설 검토" 등은 학습시킨 후에 검증 과정에 들어가야 되는 거 아니야? 그리고 그 사이에 AI 인터뷰가 들어가야지

# 확인한 선택

승인한 인터뷰 답변은 다음 학습 때 해설·예상 질문 근거에 들어간다. 따라서 인터뷰를 학습 뒤에 두면 반영을 위한 재학습이 필요하다. 사용자는 두 선택지 중 "학습 → 인터뷰 → 반영 재학습 → 검증"을 골랐다(2026-11-15). 다른 선택지는 "인터뷰 → 학습 → 검증"이었다.

# 배경

[SRC-063](user-author-experience-parallel.md) 2번은 나갔다 들어오면 학습 결과가 사라지는 문제를 고치기 위해 전시 화면에 질문·체험 링크를 항상 표시하자고 했다. 이를 학습 전에도 표시하도록 구현해 검증 화면이 학습보다 먼저 열렸다. 이 요청은 같은 문제를 최근 학습 결과가 있을 때만 표시하는 방식으로 다시 정한다.
