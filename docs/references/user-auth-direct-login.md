# 사용자 확정 — 인증 부분 인용

2026-11-13 작업 대화에서 사용자가 다음을 확정했다. 작가 정보 입력 카테고리 확장과 함께 전달됐던 요구 중 이번 인증 변경에 필요한 발언만 분리해 기록한다. 별도 팀 회의 원문을 검증한 기록이 아니다.

> 가입이 완료되면 자동 로그인하지 않고, 로그인 화면에서 직접 로그인한다.
> 회원가입 시 작가 소개와 작품 세계를 입력하지 않는다.
> 로그인 성공 후 SC-A02에 진입하고, 작가 정보를 나중에 작성·수정할 수 있다.

기존 [가입 요청 SRC-039](user-artist-auth.md)의 인증 범위에 대한 후속 확정이며, 이메일·비밀번호·비밀번호 확인으로 가입하고 로그인한다. 이메일 인증·소셜 로그인·비밀번호 강도/길이는 이 발언으로 확정하지 않는다.

# 이번 선별 요청

사용자는 같은 작업 대화에서 아래처럼 요청했다.

> 회원가입 후 자동 로그인하지 않고 직접 로그인하는 결정도 포함해 줘.
> 제외한 변경 사항은 삭제하거나 되돌리지 말고 로컬 작업 트리에 그대로 보존해 줘.

사용자는 작가 정보 입력 질문 카테고리 확장과 SC-A02 상세 수정은 이번 인증 변경에서 제외하라고 지정했다. 따라서 인증 부분은 [D-016](../decisions/D-016-artist-auth.md)의 후속 확정으로 연결하고 작가 정보 카테고리 확장은 이 출처의 반영 범위에 넣지 않는다. 사용자는 이번 단계에 선별 스테이징만 요청했으며 커밋·푸시·병합은 요청하지 않았다. 기존 출처 원문은 수정하지 않는다.
