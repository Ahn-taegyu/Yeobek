# 사용자 요청

> - 진행중 전시를 선택했는데 새 전시 만들기로 이어져.

# 반영 범위

진행 중 전시는 해당 전시명과 등록된 작품이 있는 편집 화면으로 연결한다. 회원가입에는 이름과 작가명 입력을 추가한다. 사진, 활동 이력, 키워드, 작품 세계는 기존 프로필 흐름에서 입력할 수 있다. 이메일 인증 및 이후 직접 로그인은 유지한다.
