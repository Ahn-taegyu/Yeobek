# 사용자 요청

> * 작품 선택할 때 작은 이미지 임에도 화질이 높아서 로딩이 느려 압축해줘.
> * 작품 선택하면 바로 "0. 작품명"이 보내져서 작품 기본 소개가 나오게 해줘.

이어서 같은 작업 중 다음을 요청했다.

> * 음성 오류가 생기는 이유 파악해서 고쳐
> * 전시 온보딩 화면 비율이 화면 비율 이상으로 기울어지지 않도록 전시 설명세로 크기를 고정하고 하단을 그라데이션으로 페이드 아웃하여 스코롤해서 내려보도록 해줘.
> * 작품 선택에서 작품명이 너무 길어지면 줄바꿈이 아니라 오른쪽 끝이 페이드 아웃되는 방식으로 바꿔

# 해석

"0. 작품명"은 선택한 작품의 번호와 제목(예: `1. 별이 빛나는 밤`)으로 해석했다. 이 요청은 기존의 "작품 선택만으로 질문·답변을 만들지 않는다" 결정([기능 명세](../specs/functional-spec.md), UC-06 AC-06)을 바꾼다.

음성 오류: 로컬 시연 DB의 `reply_audio` 실패 5건(AI_GENERATION_FAILED)은 2026-11-14 21:02~21:11에 몰려 있고 #39 수정 이후 음성 생성은 모두 성공했다. 남은 원인으로 음성 생성 요청을 기다린 뒤 새 `Audio`로 재생하면 모바일 브라우저가 탭 허용을 잃어 재생을 막는 문제를 보고, 탭 순간에 하나의 오디오 요소를 무음으로 열어 두고 재사용하도록 고쳤다. 실제 모바일 기기에서는 확인하지 않았다.
