# 적용 범위

행사 제공 옵션에서 Render를 제외하는 최신 사용자 정보로 반영한다. 이전 공개 모집 페이지의 파트너 목록을 현재 지원 보장으로 쓰지 않는다. Render 서비스 자체가 중단되었다는 의미는 아니다.

스택·모델·API는 추천 요청이다. 특정 유료 플랜 결제, 새 API 키 사용, 배포나 성능 검증을 완료하라는 승인으로 확대하지 않는다. 기존 일요일 마감·단일 채팅·독립 입출력·제공 API 최소 한 개 조건은 유지한다.
