# 키워드 원문과 표시 순서

- **주로 어떤 분야에서 활동하시나요?** 동양화, 서양화, 수묵화, 조각, 사진, 일러스트, 설치미술, 미디어아트, 공예, 기타.
- **작가님의 작품은 어떤 분위기인가요?** 따뜻한, 차분한, 몽환적인, 서정적인, 실험적인, 강렬한, 미니멀한, 유쾌한, 사색적인.
- **작품에서 주로 어떤 이야기를 다루시나요?** 자연, 기억, 감정, 관계, 정체성, 상상, 일상, 사회, 시간.

분야만 “기타”가 있다. 분위기·주제에는 없다. v3 요약의 “기타 포함”을 모든 범주에 확대하지 않는다. 홈의 “일러스트 · 드로잉”은 예시 텍스트이며 분야 선택지에 없는 드로잉을 새 선택지로 추가하지 않는다.

# 질문 대조

작가 7개·전시 9개·작품 6개 문구는 [SRC-043 질문지](user-artist-questionnaire.md)와 대부분 일치한다. `exhibition_message`의 “이번 전시를 통해 관람객에게 가장 전달하고 싶은 메시지는 무엇인가요?”는 Figma에 물음표가 있다. 화면 줄바꿈은 한 문장으로 저장하되 질문의 의미와 기존 ID는 바꾸지 않는다.

활동 이력은 다섯 항목 모두 선택이다. “기타”의 입력 안내는 “추가로 소개하고 싶은 활동을 입력해 주세요”다. “입력한 정보는 작가 프로필에 저장되며, 언제든 수정할 수 있어요”라는 안내가 있다.

# 사용자 결정 우선과 남은 경계

소셜 버튼과 성별은 디자인에 있으나 이메일 로그인 유지·소셜 제외 및 성별 기본 미수집 정책을 따른다. 이름·작가명·이메일은 필수이며 나머지는 건너뛸 수 있다. 작품 이미지·제작연도·크기는 별도 작품 편집에서 선택 입력한다. QR 제외, 기본 해설 원고와 AI 미리보기 별도 화면, 시험용 운영 게시 금지도 후속 사용자 결정이 우선한다. 화면이 없다는 이유로 승인·게시를 삭제하지 않는다.

관람객 섹션165:616과 W11 미리보기 화면의 상세 계약은 해당 묶음 시작 때 다시 직접 확인한다. 이 기록은 W10 입력 화면 확인 범위다.
