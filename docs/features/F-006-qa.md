# 목적과 첫 범위

11/13 최신 권고는 OpenAI `gpt-6-luna` 직접 호출로 관람 답변을 사전 검증하는 방식이다. Liner는 해설 초안을 담당하도록 역할 변경을 제안했다. 글의 구조·인용·공개 상태를 확인한 뒤 표시하고 같은 글을 낭독한다. [모델/API와 지연 계획](../research/recommended-stack.md). 이 권고는 기능 구현 완료나 사용자 최종 모델 승인이 아니다.

해설 요청과 후속 질문을 같은 채팅에서 처리한다. 현재 작품과 허용된 공통 근거를 검색해 답하며 텍스트·음성 질문과 독립적인 텍스트·음성 출력을 지원한다. 상세 문맥 규칙은 [통합 채팅 명세](../specs/chat-interaction.md)를 따른다.

# 우선순위

- 사용자 원안: **P1**.
- 현재 구현 제안: **MVP**. 사용자 원안과 상세 설계 제안을 구분한다.
- 구현 상태: 미착수. 이 문서는 기능명세이며 앱 구현 완료 표시가 아니다.

# 수용 기준

1. 답변에 근거 발췌 또는 출처 라벨을 제공하고 실제 검색된 승인 자료만 인용한다.
2. 자료에 없는 의도는 알 수 없다고 답한다. 질문이 다른 작품으로 모호하면 작품 선택을 요청한다.
3. 다른 작가·전시, 미승인/철회 자료가 검색·대화 이력·인용·캐시를 통해 유출되지 않는다.
4. 자료 안의 지시문으로 외부 URL 접속·권한 변경·시스템 지시 변경을 수행하지 않는다.
5. 실패·사용 한도·타임아웃을 답변처럼 꾸미지 않고 안내한다. 작품 전환 시 채팅 기록은 유지하고 활성 작품/부위·검색 범위만 갱신한다.
6. “이 작품”은 확인된 현재 작품으로 해석한다. “이 부분”의 위치/모양이 불명확하면 대상 설명을 요청하고 실물 지시를 보았다고 추측하지 않는다.
7. 생성 시작 시 작품·공개 버전을 고정하고 늦게 도착한 답을 해당 요청에 붙인다. 입력·출력 모드만 바꾼 경우 답변 내용과 근거를 다시 생성하지 않는다.

# 제외 및 미결정

외부 웹 검색·일반 지식 보완·구매 상담은 후속 제안이다. 음성 Q&A는 MVP에 포함한다. 부위의 대상 이름은 작가 자료나 검증한 이미지 분석 근거가 있어야 답한다. 등록 이미지의 AI 참고·터치 선택·카메라 입력은 [D-007](../decisions/D-007-visual-reference.md)에서 구분한다.
