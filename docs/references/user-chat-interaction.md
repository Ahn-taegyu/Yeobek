# 사용자 요구 원문

> 해설과 질의를 포함한 도슨트와의 모든 상호작용은 하나의 채팅에서 진행될거야. "18번 작품 설명해줘."라고 말하거나 "이 작품의 이 부분에 그려진 건 뭐야"라고 질문하듯이 상호작용할 수 있도록. 입력과 출력은 각각 텍스트와 음성으로 모드를 바꾸며 진행될 수 있고 입력이 음성이라고 해서 꼭 출력이 음성이어야 하는 건 아니고 출력이 음성이라고 입력이 음성이어야 하는 건 아니야.

# 확인된 요구

- 관람객 도슨트 경험은 해설 요청과 질문을 함께 처리하는 한 채팅이다.
- 작품 번호를 말하거나 입력해 해설을 요청할 수 있다.
- 현재 작품·직전 대화 맥락을 사용해 후속 질문을 처리한다.
- 입력 모드와 출력 모드는 별도 선택이다. 텍스트→텍스트, 텍스트→음성, 음성→텍스트, 음성→음성을 모두 지원한다.
- 이전 문서의 텍스트 전용 Q&A 가정은 이 요구로 대체된다.

# 후속 응답 — 부위를 가리키는 방식

'이 부분'을 지칭하는 방식에 대해 사용자는 다음과 같이 답했다.

> 말이나 글이 맞을 것 같은데 채팅의 이미지나 카메라로 보여주는 현실적으로 가능할까? 아니면 MVP에는 포함되지 않을 기능으로 할까

말·글을 선호한다고 밝혔고 이미지/카메라의 현실성과 MVP 적합성을 질문했다. 터치 선택이나 카메라 입력을 필수로 확정한 것은 아니다.

# 제안과 사실의 구분

assistant의 권고는 첫 MVP에서는 말·글로 부위를 설명하고 모호하면 되묻기, 이후 등록 이미지 부분 선택과 카메라 촬영을 순서대로 검토하는 것이다. 당시에는 제안이었고, 사용자가 이후 이미지 부분 선택·카메라를 후순위로 두는 데 동의했다. [최신 응답](user-build-direction.md)과 [D-007](../decisions/D-007-visual-reference.md)에 현재 결정을 기록한다. 음성 입력 자체를 후속으로 미루는 제안이 아니다.
