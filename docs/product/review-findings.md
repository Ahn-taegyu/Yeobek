# 빠진 최소 조건

전시·작품 ID, 소유권, 초안 저장, 공개 상태, 근거 승인, 음성/글 버전 일치, 생성 재시도, 삭제 후 검색 제외, 비용 한도가 필요하다. 요청한 기능이 동작하기 위한 조건으로 [기능명세](../specs/functional-spec.md)에 보완했다.

# 미확정

프레임워크·DB·호스팅·모델·음성의 첫 구현 선택은 [D-008](../decisions/D-008-technology-stack.md)에 기록했다. 아직 검증하지 않은 것은 실제 API 접근·한국어 품질·비용·지연이다. 모든 파일 자동 파싱, 결제, 실내 측위, 거래 성과, 시장점유율을 검증된 사실로 표현하지 않는다. [우선순위](mvp-priorities.md)와 [결정 목록](../decisions/index.md)에 연결한다.
