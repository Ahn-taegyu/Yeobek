- Sonnet은 자료가 없는 조건의 정상 보류 6건을 부적절하다고 잘못 평가했다. 사유에서는 자료 부재를 인정하면서 점수에서는 감점한 경우도 있었다. 평가 원점수를 품질 순위로 채택하지 않았다.

# 실제 계정 적용과 재게시

실험과 별개로 로컬 반 고흐 계정의 작가 입력 네 절을 1인칭으로 정리하고, 작품 질문 18칸을 채웠다. 출처는 별도 대응표로 보존하고, 현재 소장·보존 정보는 메모에 분리했다. 새 입력은 실제 편지의 직접 인용이 아닌 한국어 재구성이다. 화면의 계정과 전시에는 시연 표시를 유지했다.

작품별 후보 2개+평가를 실행하고 원자료와 직접 대조했다. 별밤은 제작 계기 인용을 추가하고, 침실은 당시 보랏빛과 현재 변색을 구별해 원고를 수정했다. 예상 Q&A 9개 중 2개는 화자/그림자 표현을 지시문 재작성과 별도 평가로 고쳐 최신 버전을 승인했다. 자료·원고·Q&A 승인 후 세 작품을 명시적으로 재게시했다.

첫 게시 버전 3의 관람 실호출은 6문항 중 4개 응답, 작가 미리보기 1개 성공이었다. 보류한 두 문항은 해바라기 판본과 침실 변색이었다. 소장·보존 메모에서 편집 절차 문구를 제외하고 **원문에 실제 존재하는 연속 발췌**로 승인 근거 버전을 갱신했다. 원문·문서 revision은 유지했다. 해당 해설의 인용 버전도 다시 승인하고 버전 4로 재게시한 뒤 두 문항 모두 응답했다. 버전 4 전체 6문항을 다시 실행한 것은 아니며, 생성의 과잉 보류가 완전히 해결됐다는 뜻도 아니다.

추가 API 호출: 통제 비교 59회, 실패 원인 진단 6회, 실제 앱 생성·평가·Q&A·재작성·관람·미리보기 25회. 비교의 `usage.cost` 합계는 $0.36645410, 추가 진단은 $0.000924265이며 앱 비용/잔액/총 청구액을 포함하지 않는다.
