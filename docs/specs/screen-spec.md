# 화면 명세 사용법

[기능명세 v1.0](functional-spec.md)의 화면 부속 문서다. 모든 화면은 신규 설계 제안이며 와이어프레임이나 구현 완료 표시가 아니다. 필드와 서버 규칙은 본문의 BR-01~14를 따른다. SC는 논리 화면/패널 ID이며 별도 페이지를 11개 개발하라는 뜻이 아니다. 작가 작업은 한 작업 공간의 탭으로 합칠 수 있고, 관람은 SC-V01을 중심으로 유지한다.

# 공통 구성

- **작가 작업 공간:** 전시명·초안/공개 상태·내 전시 목록·로그아웃, `작품/자료`, `검수`, `게시/배포` 이동, 저장 상태를 제공한다. 상세 작업에는 선택 작품 번호·제목을 고정 표시한다.
- **관람 화면:** 전시명, 현재 작품, 대화, 입력/출력 모드, 입력부가 기본이다. 별도 로그인·설정 가입 흐름은 없다.
- **상태:** 불러오는 중, 데이터 없음, 입력 오류, 처리 중, 성공, 처리 실패, 권한/공개 차단을 구별한다. 재시도 버튼은 같은 작업에 연결한다.
- **변경 보호:** 미저장 이탈은 계속 편집/저장 후 이동/버리기. 삭제·중지·철회는 대상과 영향 범위를 확인한다. 일반 저장·패널 닫기에는 불필요한 확인을 넣지 않는다.
- **접근성:** 보이는 라벨·키보드 포커스·색상 외 상태 표식·이미지 대체문을 제공한다. 동작 버튼은 터치하기 쉬운 크기로 설계하고 모바일 키보드 위에 입력부를 유지한다.

# SC-A01 작가 로그인

**목적/전제:** 사전 생성된 작가 계정으로 자기 전시에 접근한다. 관람객 로그인 화면으로 사용하지 않는다. OP-01, BR-01.

| 화면 영역 | 표시·입력 | 동작/조건 |
| --- | --- | --- |
| 안내 | 서비스명, 작가 관리 화면 안내 | 관람객 기능과 구분 |
| 폼 | 이메일, 비밀번호, 표시/숨김 | 이메일 형식·필수값만 선검증, 비밀번호 정책을 로그인에서 새로 제한하지 않음 |
| 주 행동 | `로그인` | 필수값 유효 시 가능, 진행 중 중복 제출 방지 |
| 오류 | 필드/인증/네트워크 안내 | 어느 계정이 존재하는지 구별해 노출하지 않음 |

- 성공: 소유 전시 목록 또는 권한 검증된 원래 작업으로 이동한다. 외부 URL을 임의 복귀 경로로 사용하지 않는다.
- 실패: 이메일은 유지, 비밀번호는 브라우저 메모리 외 저장하지 않는다. 재시도 가능 여부를 표시한다.
- 세션 만료: 같은 탭 재인증 동안 가능한 미저장 입력은 메모리에서 유지하되 자동 저장·자동 재승인하지 않는다. 다른 계정으로 로그인하면 이전 작가 초안을 지운다.
- 공개 회원가입·비밀번호 찾기는 이번 화면에 제공하지 않는다.

# SC-A02 내 전시 목록·전시 생성

**목적/전제:** 자기 전시를 찾거나 새 전시를 만든다. OP-02, BR-01.

| 영역 | 내용 | 동작 |
| --- | --- | --- |
| 헤더 | 작가 계정 표시, `전시 만들기`, 로그아웃 | 생성 폼 열기/세션 종료 |
| 전시 카드/행 | 제목, draft/published/paused의 사용자용 라벨, 작품 수·공개 수, 최근 수정 | 선택→SC-A03 |
| 생성 폼 | 전시 제목, 선택적 작가명·기간·장소 | `만들기` 성공 시 새 전시 ID의 SC-A03 |
| 빈 상태 | “첫 전시를 만들어 보세요” | 생성 CTA |

로딩 중은 빈 목록과 구별한다. 목록 오류는 목록 재조회로 복구한다. 생성 연속 클릭/응답 유실은 같은 request ID로 결과를 확인해 전시가 중복 생성되지 않게 한다. 목록에서 전시 영구 삭제·예약 게시·결제 동작은 제공하지 않는다.

# SC-A03 전시 작업 공간

**목적/전제:** 전시 준비 상태와 다음 작업을 한눈에 본다. 소유권 확인 후 진입한다. OP-03~04, OP-08, OP-12.

| 영역 | 내용 | 행동/조건 |
| --- | --- | --- |
| 전시 헤더 | 제목·공개 상태, 현재 공개 수, 변경 미게시 표시 | `게시/배포`→A06 |
| 기본 정보 | 제목·공개 작가명·기간·장소 | `저장`; 공개 중이면 “저장한 변경은 게시 후 반영됩니다” |
| 준비 요약 | 자료 부족/검수 필요/음성 필요/게시 가능 개수 | 해당 작품/상태로 이동 |
| 작품 목록 | 번호·썸네일·제목, 초안 준비 상태와 공개 상태를 별도 표시 | `편집`→A04, `검수`→A05 |
| 목록 도구 | 번호/제목 검색, 준비 상태 필터, `작품 추가` | 새 작품 폼 A04 |

빈 전시는 작품 추가 안내를 보인다. 전시 제목이 없어도 텅 빈 새 레코드를 자동 생성하지 않는다. 조회 실패/타인 ID에는 편집 UI를 먼저 그리지 않는다. 번호순 정렬을 기본으로 하고 드래그 재정렬을 범위에 추가하지 않는다. 전시 정보만 저장해 공개 내용을 바로 바꾸지 않는다.

# SC-A04 작품·자료 편집

**목적/전제:** 작품을 식별하고 생성·검수에 필요한 자료를 연결한다. OP-04~07, OP-13, BR-01~03·06~07.

| 영역 | 필드/정보 | 행동 |
| --- | --- | --- |
| 작품 정보 | 번호, 제목, 제작연도·재료·크기 | 필수/선택·길이·번호 충돌 인라인 표시 |
| 대표 이미지 | 미리보기, 파일명·크기, 업로드 상태 | 추가/교체/초안 연결 제거; 완료 전 공개 이미지로 사용 금지 |
| 비공개 메모 | 자유 입력, “이 메모는 그대로 공개되지 않아요” | 필요한 부분을 근거 초안에 등록 |
| 도록 보관 | PDF 목록·파일명·업로드 상태 | 업로드, 소유자 원본 열기, 삭제; “PDF 내용은 직접 발췌해 주세요” |
| 근거 편집 | 본문, 출처 라벨, 파일·쪽수, 해당 작품/전시 공통 | 추가/수정/초안 제외; 공개 승인 여부는 별도 표시 |
| 저장 영역 | 저장 상태/시각, 공개본 유지 안내 | `저장`, `저장 후 검수`, 목록 복귀 |
| 위험 행동 | 작품 삭제, 자료 삭제/공개 근거 철회 | 영향 조회 후 별도 확인, 단순 초안 제외와 구별 |

**활성 조건:** 번호·제목이 유효하면 불완전 자료 상태로도 초안 저장 가능하다. `저장 후 검수`는 저장 성공 후 이동하되 근거가 부족하면 A05에서 부족 항목을 안내한다. 필드/파일 상한은 기능명세 4.1을 그대로 사용한다.

**세부 동작:** 전시 공통 PDF·근거는 같은 파일을 매 작품마다 다시 올리지 않고 기존 자료에서 연결할 수 있다. 공개 근거 수정은 새 초안으로 저장한다. 활성 공개 자료를 제거하려면 “초안에서 제외”와 “공개 철회”의 결과를 명확히 구분한다. 공개 파일의 교체/삭제는 참조 검사 없이 덮어쓰지 않는다.

**예외 상태:** 중복 번호→번호 필드 유지·수정; 파일 오류→문제 파일만 재선택; 업로드 중→텍스트 편집 가능·해당 파일 사용 불가; 충돌→로컬 입력 보존·최신본 조회; 공개 중 번호 변경→게시 시 적용/라벨 재출력 안내. 외부 전시·다른 작가 자료 선택은 허용하지 않는다.

# SC-A05 생성·검수·음성 준비

**목적/전제:** 근거와 해설을 대조해 승인하고 음성을 준비한다. OP-08~11, OP-20, BR-03~04.

| 영역 | 표시 정보 | 행동/활성 조건 |
| --- | --- | --- |
| 선택 작품 | 번호·제목·이미지, 초안/공개 상태 | 다른 작품 선택 전 미저장 보호 |
| 근거 패널 | 선택 근거 본문·라벨·쪽수·공개 승인 상태 | 원본 확인(작가 전용), `근거 공개 승인`, 초안 수정 연결 |
| 해설 편집 | 생성 후보/편집본, 인용 근거, 글자 수, 검토 경고 | `초안 생성`, `재생성`, `저장`, 후보 적용/기존 글 유지 |
| 검수 확인 | 근거 준비 여부, 미승인 인용/변경 충돌 | `해설 승인`: 저장 완료+사용 근거 공개 승인 조건 |
| 기본 음성 | 미준비/생성 중/준비/실패/오래된 음성, 같은 승인 글 | `음성 만들기`, `재시도`, `재생/일시정지` |
| 다음 행동 | 미해결 조건 목록 | `게시/배포로 이동`→A06; 이동과 게시 실행은 별개 |

넓은 화면은 근거와 해설을 나란히 놓고, 좁은 화면은 순서가 분명한 접이식 영역으로 만든다. 원본 PDF·승인 전 음성 미리보기는 인증된 관리자 경로로만 열며 공개 API를 우회하지 않는다.

**상태별 제어:** 근거 없음→생성 비활성+자료 입력 CTA; 생성 중→중복 생성 비활성; 후보 도착→자동 덮어쓰기 없음; 인용 오류→승인 비활성; 승인 후 수정→재승인 필요/음성 stale; 음성 실패→승인 글 보존·음성만 재시도; 이전 공개본 존재→관람에 제공되는 버전 별도 표시.

실시간 관람객 답변을 이 화면에 모아 일일이 승인하는 기능은 만들지 않는다. 전체 버전 이력 비교 도구 대신 현재 공개본·편집본·이번 생성 후보를 구별할 수 있는 정도로 구성한다.

# SC-A06 게시·중지·배포

**목적/전제:** 무엇이 공개되는지 검토하고 QR을 배포한다. OP-12~14, BR-05~08.

| 영역 | 정보 | 행동/조건 |
| --- | --- | --- |
| 전시 공개 요약 | 현재 공개/중지 상태, 공개 작가명·기본 정보의 변경 여부 | `전시 정보만 게시`: 기존 공개 작품이 있을 때 |
| 작품 준비 표 | 선택 체크, 공개 번호·제목, 근거/해설/음성 준비, 현재 공개 버전 | 준비 미완료 항목은 이유와 A04/A05 링크 |
| 게시 행동 | 게시할 작품 수·유지할 기존 작품 수 | 최초 `공개 시작`, 이후 `선택 변경 게시`; 선택 전체 검증 |
| 공개 관리 | 현재 공개 작품 목록 | `작품 공개 중지`, `전시 전체 중지`, 조건 충족 시 `다시 공개` |
| 배포 | 전시 URL·QR, 작품 URL, 인쇄 안내 | `링크 복사`, `관람 화면 열기`, `라벨 인쇄`→A07 |

**게시 확인:** 선택 작품·변경 정보·유지할 작품·누락된 준비 항목을 보여준다. 서버에서 조건이 바뀌면 확인 창에 최신 사유를 표시하고 일부만 성공한 것처럼 진행하지 않는다. 중지 확인은 전시 전체/작품 하나의 영향을 분명히 표시한다.

**상태:** 최초 미공개는 배포 버튼 대신 게시 준비 안내; 공개 성공은 성공 시각·공개 작품과 링크 표시; 수정 초안은 공개 링크와 미게시 변경을 함께 표시; 중지 상태는 링크 자체는 유지하되 “현재 관람 불가” 표시와 새 인쇄 비활성. 게시 실패 시 기존 링크·공개 버전을 유지한다.

번호 변경 후 게시 성공 시 라벨 재출력 안내를 남긴다. 해설만 바뀐 경우 QR 재발급을 요구하지 않는다. QR 조회 수를 관람객 수/스캔 분석으로 보여주지 않는다.

# SC-A07 인쇄용 QR·번호 라벨

**목적/전제:** 실제 현장에 부착할 출력물을 만든다. 현재 공개 전시·작품만 대상이다. OP-14~15, BR-06·09.

| 영역 | 내용 | 행동 |
| --- | --- | --- |
| 인쇄 설정 | 공개 작품 선택, `전시 QR+번호 라벨` 기본, `작품 QR 포함` 선택 | 선택한 공개 항목으로 미리보기 |
| 전시 안내 | 전시명·작가명, 전시 QR, 짧은 시작 안내·대체 URL | 일반 휴대폰 카메라로 진입 가능 |
| 작품 라벨 | 공개 번호·제목, 선택 시 작품 QR | 초안의 새 번호가 섞이지 않음 |
| 도구 | A4 미리보기, 브라우저 인쇄/저장 안내 | `인쇄 / PDF로 저장`은 브라우저 인쇄 대화상자 |

인쇄 직전 공개 상태·번호를 다시 확인한다. 변경되면 최신 라벨을 재구성한 뒤 다시 인쇄하도록 한다. 출력에는 관리자 메뉴·버튼·비공개 정보가 없어야 한다. 브라우저 인쇄 취소는 게시 상태를 바꾸지 않는다. 앱 내 PDF 엔진·단축 URL 서비스·NFC 제작은 필요하지 않다.

# SC-V01 통합 도슨트 채팅

**목적/전제:** 해설·질문·작품 전환·네 입출력 조합을 한 대화에서 수행한다. OP-15~20, BR-08~14.

## 정보 배치

| 영역 | 표시 정보 | 행동 |
| --- | --- | --- |
| 상단 | 전시명·작가명, 선택적 기간/장소 안내 | 작품 목록 열기; 공개 확인 중이면 로딩 |
| 현재 작품 | 번호·제목·대표 이미지, 선택 없을 때 안내 | `작품 바꾸기`→V02, `해설 보기`→같은 채팅 요청 |
| 대화 영역 | 질문/인식문, 대상 작품 라벨, 답변·출처·상태 | 메시지별 글 펼치기/출처/듣기/재시도 |
| 독립 모드 | `입력: 글/음성`, `출력: 글/음성` | 한쪽만 변경해도 다른 모드·기록·작품 유지 |
| 작성 영역 | 글 입력+500자 표시 또는 녹음/인식문 확인 | 명시적 전송, 전송 중 2차 질문 잠금 |
| 이용 안내 | 작가 공개 자료 기반 AI, AI 음성, 탭 내 대화/임시 처리 안내 | 모드·마이크 이해에 필요한 짧은 설명 |

첫 전시 진입은 “작품을 고르거나 ‘18번 설명해줘’처럼 입력해 보세요”와 작품 선택을 제공한다. 작품 QR은 해당 카드만 설정하며 자동 낭독/자동 마이크 요청을 하지 않는다. 같은 탭·전시 기록은 검증 후 복원하고 QR이 지정한 작품을 현재 대상으로 적용한다.

## 입력/응답 상태

| 상태 | UI와 가능한 동작 |
| --- | --- |
| 글 작성 | 입력·수정 가능, 공백/초과 시 전송 비활성, 유효 질문 전송 |
| 녹음 전 | 녹음 시작, 출력 모드는 그대로 |
| 녹음 중 | 경과/제한 시간, 종료·취소; 30초/3MB 도달 시 종료 안내 |
| 녹음 완료 | `음성 인식`, `다시 녹음`, `취소`; 자동 채팅 전송 없음 |
| 인식 중 | 처리 상태·이탈/폐기 안내; 중복 인식 비활성 |
| 인식문 확인 | 수정 가능한 글·글자 수, `전송`, `다시 녹음`, `취소` |
| 답변 중 | 원래 질문 아래 처리 표시, 모드/목록 변경 가능, 추가 전송 잠금 |
| 글 답변 | 본문·공개 출처 버튼, 수동 듣기; 자동 낭독 없음 |
| 음성 답변 | 음성 준비/재생 버튼·진행 상태, `글 보기`, `출처 보기` |
| 음성 실패 | 같은 글 표시/펼치기·`낭독 다시 시도`; 질문 재전송과 구별 |
| 확인 필요/근거 부족 | 일반 대화 메시지와 다음 선택/설명 안내; 기술 오류 재시도 버튼 없음 |
| 공개 중지/교체 | 관련 내용·재생 차단, 새 공개본 확인 또는 V04 안내 |

음성은 한 번에 한 메시지만 재생한다. 재생/일시정지/처음부터 듣기를 제공한다. 음성 출력 모드에서도 인식문과 답변 글/출처를 확인할 수 있지만 항상 모두 펼쳐야 하는 것은 아니다.

## 전환·기록 규칙

- 작품 전환 중 입력한 글은 유지하되 새 대상 라벨을 보여주고 자동 전송하지 않는다. 미전송 녹음/인식문이 있으면 `계속 작성 / 버리고 작품 변경`을 확인한다.
- 명시적 번호를 포함한 요청의 서버 해석 결과는 요청 이후 다른 작품 선택이 없을 때만 현재 작품을 갱신한다. 늦은 결과가 새 선택을 되돌리지 않는다.
- 요청 중 출력 모드를 바꾸면 도착 시 현재 모드를 적용한다. 작품이 달라졌으면 원래 메시지에 붙이고 자동 낭독하지 않는다.
- 대화를 읽으며 위로 스크롤 중이면 새 답 도착 시 강제로 맨 아래로 이동시키지 않고 새 메시지 표시를 제공한다.
- 통신 오류는 질문 글과 요청 위치를 유지한다. 재시도는 동일 요청 상태부터 조회한다. 오프라인에서는 새 생성/전송을 막고 자동 재전송하지 않는다.
- 오래된 기록의 공개 버전을 확인하기 전 답변·출처·미디어를 잠깐이라도 표시하지 않는다. 서버 답변 TTL만 만료되고 공개 버전이 유효하면 로컬 글은 볼 수 있지만 낭독 재시도는 차단한다. 로컬 기록은 새로운 사실 근거로 쓰지 않는다.

# SC-V02 공개 작품 선택 패널

**목적:** 채팅을 유지하며 작품을 찾는다. OP-15, BR-09. 모바일은 시트/전체 높이 패널, 넓은 화면은 보조 패널로 구현할 수 있다.

| 영역 | 표시/동작 |
| --- | --- |
| 상단 | 전시명, 닫기, 번호/제목 검색 |
| 목록 | 번호 오름차순의 공개 작품 번호·제목·썸네일, 현재 선택 표시 |
| 선택 | 공개 상태 재확인→현재 작품 변경→부위 초기화→V01로 복귀; 선택만으로 질문 자동 전송 없음 |
| 검색 없음 | “일치하는 작품이 없어요”, 검색 지우기; 전체 공개 작품 없음과 구별 |
| 로딩/실패 | 목록 로딩, 목록 다시 불러오기; 기존 대화는 유지 |

이미지 오류는 대체 이미지·번호·제목으로 탐색을 유지한다. 검색으로 비공개 번호 존재를 알려주지 않는다. 열어둔 동안 작품이 중지되면 선택 실패를 알리고 목록을 갱신하며 이전 현재 작품을 임의 변경하지 않는다.

# SC-V03 답변 근거 패널

**목적:** 해당 답변의 공개 근거를 확인한다. OP-15/17, BR-08·10.

표시 순서는 대상 작품, `승인 해설` 또는 `AI 답변` 구분, 출처 라벨·쪽수·허용 발췌다. 답변 전체를 작가가 승인했다고 오인시키지 않는다. 내부 evidence ID, 원본 파일 경로, 원본 다운로드 버튼은 노출하지 않는다.

현재 공개 상태를 재검사하고 철회/교체된 근거는 표시하지 않는다. 출처가 없는 확인 질문/근거 부족 메시지에는 빈 출처 패널 버튼을 만들지 않는다. 닫으면 원래 메시지 위치로 복귀한다.

# SC-V04 공개 이용 불가

**목적:** 잘못된 URL·미공개·중지·삭제에 일관되게 대응한다. OP-15, BR-07~08.

| 상황 | 화면과 복구 |
| --- | --- |
| 전시 전체 접근 불가 | “현재 이용할 수 없는 전시예요. 전시장 안내를 확인해 주세요.”, 공개 상태 다시 확인 |
| 작품만 이용 불가, 전시 공개 | 해당 작품 내용을 숨기고 “이 작품은 현재 안내할 수 없어요”, 공개 작품 목록으로 이동 |
| 일시 통신 실패 | 이용 불가 확정과 구별해 “연결을 확인해 주세요”, 재시도 |
| 공개 작품 0개 | 전시 paused 상태의 이용 불가 안내; 빈 채팅에서 계속 질문하게 두지 않음 |

사전에 공개되지 않은 전시명·작품명·소유자를 오류 화면에 노출하지 않는다. 미존재/비공개/삭제를 구분해 내부 상태를 추측하게 하지 않는다. 전체 중지 시 질문·녹음·음성 재생을 차단한다. 작품 중지 후 다른 공개 작품 탐색은 가능하다.

# 제작할 화면과 상태

11개 논리 화면의 기본 상태와 아래 변형을 와이어프레임에 포함한다. SC-A03~A06은 작업 공간 탭, SC-V02~V03은 V01의 보조 패널로 합칠 수 있다. 화면 수보다 상태/이동 누락 여부가 완료 기준이다.

| 묶음 | 필수 프레임/상태 |
| --- | --- |
| A01~A03 | 로그인 오류·만료, 전시 없음/있음, 새 전시, 준비 단계 혼재 작품 목록 |
| A04 | 정상/필수 오류/중복 번호, 업로드 진행·실패, 수동 PDF 발췌, 미저장 이탈·편집 충돌 |
| A05 | 자료 없음, 생성 중/후보/실패, 근거·해설 승인, 수정으로 승인 무효, 음성 준비/실패 |
| A06~A07 | 최초 게시 불가/가능, 일부 작품 선택, 재게시, 전체/작품 중지, 영향 철회 확인, A4 인쇄 |
| V01 | 첫 진입/작품 QR, 네 입출력 조합, 녹음→인식문 수정, 답변 대기·작품 전환, 음성 실패·재생 차단 |
| V02~V04 | 검색/결과 없음/이미지 실패, 근거 확인, 자료 부족, 공개 중지/잘못된 URL/통신 실패 |
| 복원·만료 | 새로고침 검증 중, 저장소 불가, 서버 답변 만료, 오래된 공개 버전 차단 |

프레임에는 SC ID·관련 BR·연결 UC, 버튼의 활성/비활성 조건, 눌렀을 때 이동/요청 OP, 저장/유지되는 상태를 주석으로 남긴다. 최소 좁은 모바일 1종과 넓은 관리자 1종으로 구성·스크롤·고정 조작부를 확인하며 실제 기기 검증은 별도 수행한다.
