# 해석 경계와 후속 질문

이름·작가명·이메일 필수는 로그인 후 온보딩 범위다. 이메일은 가입 인증 정보가 이미 있으므로 별도 재입력 요구 여부는 구현 전에 정리한다. 성별 수집은 명시 답변이 없으며 v3 기본인 미수집을 유지한다. 미공개이면서 종료일이 지난 전시의 탭 우선순위는 W10에서 확인한다.

QR 제작 기능과 별도 “도슨트 여운” 화면 후보는 MVP 범위에서 제외한다. 공개 전시 주소·채팅·승인·게시는 유지하는 안으로 후속 확인을 요청했다. 기존 F-008 ID와 최초 P1 이력은 보존한다. 기존 서버 계약은 삭제하지 않는다.

A4·A7의 검수 화면 구성·R2는 확정되지 않았다. 직접 수정은 최종 답변 문장 편집, AI 지시문 수정은 요청에 따라 새 초안을 생성하고 다시 검수하는 차이를 설명했다. 기본 해설 원고 확인과 질문형 미리보기는 같은 화면에 둘 수 있어도 승인 대상을 구분한다고 설명했다. 모의 해설은 실제 API 없이 시험 코드가 만든 답변이며 실제 AI 결과의 검수 후 시연과 다르다고 설명한 뒤 선택을 다시 요청했다. 설명 자체를 사용자 선택으로 기록하지 않는다.
