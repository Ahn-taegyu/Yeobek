# 목적과 첫 범위

전시 URL의 QR 제작은 보류한다. 공개 전시 URL로 SC-V05에 진입하고 작품은 채팅에서 선택한다. 기존 공개 조회·번호 라벨 서버 계약을 유지한다.

# 우선순위

- 사용자 원안: **P1**.
- 현재 범위: **Hold**. 사용자가 v3에서 QR 제작을 MVP에서 제외했다.
- 구현 상태: 미착수. 이 문서는 기능명세이며 앱 구현 완료 표시가 아니다.

# 수용 기준

아래는 QR 범위를 재개할 때 적용할 기존 기준이다.

1. 실제 휴대폰으로 전시 QR을 열면 공개 확인 후 같은 전시의 소개가 열린다.
2. 설명 수정·재승인·재게시 후 같은 URL과 QR이 최신 공개 버전을 연다.
3. 중지·삭제된 전시 URL은 공개 내용을 숨기고 상태를 안내한다.
4. 인쇄 가능한 A4 화면/브라우저 PDF 저장으로 라벨을 제공한다. 앱 내 PDF 엔진은 필수가 아니다.
5. 작품 선택은 채팅 목록에서 동작하며 기록과 음소거 상태를 유지한다.

# 제외 및 미결정

동적 단축 URL 서비스·스캔 분석 도구는 필수 아님. QR 요청 수를 실제 관람객 수로 보고하지 않는다.
