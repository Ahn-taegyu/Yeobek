# 목적 정정

> 위키는 AI가 정보를 가져오기 위한 것이지 사용자에게 보여주기 위한게 아니야

# 후속 질문

> 작가는 자기 위키를 볼 수 있도록 해야할까?

후속 질문은 별도 위키 화면을 추가하라는 확정 지시가 아니다. 작가 정보 입력·수정과 기존 근거 검수에서 AI 참고 정보를 확인하도록 보완하고 전체 위키 탐색은 후순위로 두자는 답변은 에이전트의 제안이다. 관람객용 위키를 제공한다는 의미로 해석하지 않는다.
