# 결정 상태

**accepted** — [사용자 응답](../references/user-business-scope.md)으로 확정했다. [D-001](D-001-business-scope.md)의 “사업안 1/2는 미정”을 대체한다.

# 내용

사업안은 **1번: AI 도슨트를 제공하는 우리 회사를 한 명이 운영할 수 있게 만드는 사업**이다. 1인 운영의 주체는 우리 회사이고, AI 도슨트는 고객(작가·전시 운영자)에게 판매하는 핵심 서비스다. 우리 매출은 도슨트 서비스 이용료이며 고객의 입장료·작품 판매 대금과 구분한다.

# 유지되는 것

- 공통 도슨트 흐름(자료 입력 → 검수 → 글·음성 해설 → 게시 → 질의응답)을 먼저 완성한다는 D-001의 개발 순서.
- 입장권·작품 판매·구매 문의·결제는 개발 범위에 넣지 않는다. 2번의 거래 흐름은 채택하지 않았다.
- 인식 방식, 단일 채팅과 독립 입출력, 기술 스택 등 다른 확정 결정(D-002, D-006~D-013).

# 확정되지 않은 것

1번 채택으로 “고객이 늘어도 제작·지원 업무를 한 명이 감당할 수 있는가”가 입증 대상이 된다. 그러나 이를 위한 운영 자동화의 구체 범위는 아직 제안이며 이 결정에 포함되지 않는다.

| 제안 | 현재 기준 | 필요한 결정 |
| --- | --- | --- |
| AI 작업 기록과 재시도 | 논리 모델의 GenerationJob, 미구현 | 구현 시 필드·보존 기간 확정 |
| 자료 부족 질문의 저장과 작가 보완 요청 | [D-005](D-005-measurement.md): 질문 원문 저장은 P2 | 최소 저장 범위·보존 기간·관람객 안내 |
| 회사 운영 화면 | 기능명세 3절: 운영자 전용 UI는 범위 밖 | 읽기 전용 화면 추가 여부 |
| 작가 직접 가입 | 사전 발급 계정 | 마감 이후 재검토 |
| Alt·스티비·채널톡 연동 | 공통 도슨트 완주 전 추가 연동 없음 | 공통 흐름 완주 후 재검토 |
| 초안과 함께 작가에게 물어볼 질문 생성 | F-012 AI 인터뷰는 P2 | 선택 기능 채택 여부 |

지불 의향, 실제 사용 의향, 공급자 작업 시간은 검증되지 않았다. 1번 채택이 수요나 사업성 검증을 뜻하지 않는다.

# 영향

제품 설명과 시연은 “작가가 입력·승인하면 운영자의 수작업 없이 도슨트가 제공된다”를 중심으로 구성한다. 현재 구현 상태와 기능 우선순위(MVP/P2/Later)는 이 결정으로 바뀌지 않는다.
