# 사용자 결정 및 구현 경계

예상 질문 수는 화면 행 개수 대신 SRC-050의 작품 최대3·전시 최대5를 따른다. “정확해요”는 평가 기록이며 승인·게시가 아니다. 수정 저장은 새 작업본과 출처 검수로 이어지고 즉시 공개하지 않는다. 기존 기본 해설 원고 화면과 AI 미리보기는 별도로 제공한다. 디자인에서 보이지 않는 승인·철회·공개 단계도 유지한다.

수정 예시의 의미 추가가 실제 근거에 있는지는 디자인으로 확인할 수 없다. 지시문을 승인 사실로 쓰지 않고, 새 사실은 작가가 별도로 명시한 근거 후보의 검수·승인을 거친다. 이미지·음성 아이콘은 확인했지만 W11 서버의 새 음성 입출력 범위가 자동 확정된 것은 아니다. 관람 미디어와 음성 계약은 W12 원문 및 기존 API와 대조한다.
